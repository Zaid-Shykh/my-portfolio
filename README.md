# My Portfolio

A responsive personal portfolio built with React, Vite, and CSS.

## Run locally

1. Install Node.js (LTS).
2. Open this folder in VS Code.
3. Open the terminal and run:

```bash
npm install
npm run dev
```

4. Open the local URL printed by Vite (usually http://localhost:5173).

## Personalize before publishing

Search `src/App.jsx` for:
- `your.email@example.com` — replace with your real email.
- GitHub and LinkedIn URLs — replace with your profile links.
- Project descriptions — update them to match your final project details.
- Education and skills — verify the details are current.

The hero portrait is currently a designed initials graphic. You can replace it with your own photo later.

## Build for deployment

```bash
npm run build
```

Vite creates the production site in the `dist` folder.
